# PER-802 — разведка

Ветка `feature/PER-802` от `origin/develop` 7582e10 (27.10.2026). Разведка — основной исполнитель, без подагентов.

## Постановка (дословно из Linear)

**Переработать корень аукциона и пульт администратора**

Что сделать (предложение оркестратора, принято владельцем как направление):

1. **Корень у администратора** — те же ряды, что у участника, и один ряд «🛠 Пульт» над возвратом; «Сеты», «Объявление», «Промо-видео» (и «Ставки зала» в финале) уходят в пульт.
2. **Пульт до открытия недели — чек-лист подготовки** с отметками ✓/✗: лоты с ценой и шагом, сроки недели, сходка опубликована, розыгрыш и приз, аукцион опубликован; под ним — кнопка следующего шага, затем настройки группами, опасное («Удалить аукцион») — в «Ещё» внизу.
3. **Пульт во время торгов** — группы вместо плоского списка: «Торги» (сортировка, сводка дня, «Счастливые часы»), «Участникам» (объявление, промо-видео), «Розыгрыш» (приз, фото, итог), «Финал» (отбор лотов), «Сеты», «Порядок», «Ещё» (отмена аукциона).
4. **Приз** — один экран «Приз» с текстом и фото на любом этапе до итога (сейчас фото только после открытия недели).
5. **«В финал · <лот>» по кнопке на лот** — в отдельный экран «Финал» со списком и отметками.
6. **Сортировка** «Ставки / Люди / Рост» — одна кнопка-переключатель.

Границы: экраны участника, тексты вестей и команды Auction не трогать. Раскладку рядов участника — по PER-798, «Статистику» — по PER-800, их не переигрывать. Старые `callback_data` пульта из уже отправленных сообщений должны открывать новый пульт, а не падать.

Критерии: L0 корень администратора = участнические ряды + один «🛠 Пульт»; L0 чек-лист — каждое из пяти условий и меняется после команды; L0 «Приз» с фото до открытия недели; старые кнопки пульта открывают новый пульт (тест с пересозданным ботом); линтер экранов и матрица доступа зелёные; дизайн-код и hub-bot.md в ногу.

Чекпоинт: план экранов комментарием в задаче и стоп до ответа владельца.

### Текущий пульт вне финала (`consoleScreen`)

Ряды по порядку: `[Ставки][Люди][Рост]` → (draft/scheduled) `[Сроки недели][Опубликовать|Снять с публикации]` → `[Время финала][🗑 Убрать время финала][Изменить приз][Фото приза]` по условиям → (не окна) `[Сводка дня][Отменить аукцион][Порядок]` → (scheduled со сроками) `[Вкл · Финал в зале]`, `[Счастливые часы][Сводка дня][Порядок]`, `[Розыгрыш][Срок оплаты]`, `[Приз|Изменить приз]`, `[🗑 Убрать розыгрыш]`, `[🗑 Убрать приз]`, `[Открыть онлайн-неделю]` → (prebidding) `[Счастливые часы][Сводка дня][Отменить аукцион][Порядок]` → (editable) `[🗑 Удалить аукцион]` → `[Итог розыгрыша]` → `[Счета]` → (break) `[Объявить состав финала]` → (prebidding) по ряду `[В финал · <лот>]` на лот страницы → листание → `[‹ Аукцион]`.

## Опорные факты

- Старые кнопки: все `v1:ac:*` разбирает `parseConsole`; данные «Сетов» (`consoleSetsData`), «Объявления» (`consoleAnnouncementData`), «Промо-видео» (`consolePromoVideoData`), «Ставок зала» (`floorData`) и экраны за ними остаются — переезжает только вход. `v1:ac:v:<a>[:page[:sort]]` старых сортировок и `v1:ac:s|d:<a>:<lot>:<page>[:sort]` отметки финала надо продолжать принимать: первое → новый пульт (сортировка из хвоста сохраняется), второе → команда и экран «Финал».
- Фото приза до открытия недели **Auction не принимает**: `apps/auction/.../raffle/Raffle.scala:333–345` `beforeResult` — `RaffleState.Initial` → `RaffleNotFound`; entity розыгрыша открывает аукцион после `PrebiddingStarted`. Текст приза до открытия живёт в конфигурации недели (`week.rafflePrize`, `ScheduleAuction`), фото — только у entity розыгрыша. Пункт 4 / критерий «Приз с фото до открытия недели» упирается в границу «команды Auction не трогать» → вопрос владельцу.
- «Сходка опубликована» в снимке пульта нет. Источник — Meetups по id сходки из `auction-parents.ts` (после рестарта бота пусто) либо отказ `MeetupHidden` на «Открыть онлайн-неделю». → в плане пункт «?» при незнании.
- «Лоты с ценой и шагом»: `LotView.status.kind` — `draft` (нет условий) vs `scheduled`; считается из `console.lots`.
- Предел рядов пульта — 13 (дизайн-код, 166); группы-подэкраны снимают давление на потолок.
- Пульт финала живой (`live-console.ts`) — добавление ряда «🛠 Ставки зала» в `finalScreen` правки механизма не требует.
