# Archive

Исторические материалы, не являющиеся источником актуальных решений.

- `snapshots/` — датированные общие и визуальные срезы;
- `product/` — прежние продуктовые формулировки;
- `services/` — старые технические ТЗ, прототипы и материалы аукционной ветки;
- `context/` — исходные исторические обсуждения.

Каждый материал используется только для восстановления истории или извлечения знаний. Текущий контекст находится в [PROJECT_CONTEXT.md](../PROJECT_CONTEXT.md) до завершения синхронизации, затем — в профильных документах.
