# Standard: Записи «Что нового»

> **Статус:** Active  
> **Применимость:** pull request, после которого человек увидит в боте изменение, — в любом компоненте, не только в пакете ботов  
> **Связанные документы:** [ADR-069](../../decisions/ADR-069-release-notes-as-environment-data.md), [дизайн-код, «Что нового»](../../design/bot/design-code.md#что-нового), [branching.md](branching.md)

Standard задаёт, когда pull request несёт запись «Что нового» и где она лежит.

## Правила

- Pull request, после которого человек увидит в боте изменение — новое, исправленное или убранное поведение, текст или кнопку, — несёт запись: файл `apps/hub-bot/release-notes/<id>.txt`. Изменение в другом сервисе, видимое людям через бота, кладёт запись туда же: бот пересобирается тем же мержем.
- Одно видимое изменение — одна запись. Изменение, которого человек не заметит, — рефакторинг, тесты, документация, инфраструктура, — записи не несёт.
- Имя файла — идентификатор записи: строчные латинские буквы, цифры и дефисы, до 64 знаков. Первая строка файла — поверхности, которые покажут запись: `hub`, `auction` или `hub auction`; затем пустая строка и текст.
- Форму текста задаёт дизайн-код, раздел [«Что нового»](../../design/bot/design-code.md#что-нового); здесь она не повторяется.
- Запись не удаляется и не переименовывается: новое имя — новая запись, её объявят снова, а старая пропадёт из прошлых постов. Текст исправлять можно: пост покажет исправленный, уже доставленная сводка останется как была.

## Пример

```
hub auction

Под сводкой аукциона теперь кнопка на каждый лот.
```

Файл `apps/hub-bot/release-notes/auction-summary-lot-buttons.txt`.

## Проверка

Форму каждой записи проверяет тест пакета ботов `src/core/release-notes.test.ts` (рецепт `just hub-bot-test`), и тот же разбор отказывает в старте процессу с битой записью. Есть ли запись в pull request с видимым изменением и не удалена ли или переименована прежняя, механически не проверяется: это ловит ревью, пока нет проверки в CI по метке задачи ([ADR-069](../../decisions/ADR-069-release-notes-as-environment-data.md), «Последствия»).
