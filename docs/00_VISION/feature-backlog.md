## До сходки: убрать оргхаос

| Идея | Суть | 💥 | 🔨 |
|---|---|---|---|
| Голосование за дату (мини-Doodle) | опрос по датам → победившая дата становится карточкой сходки; снимает главный блокер «а когда всем удобно» | высокий | низкий |
| Витрина «кто придёт» | аватарки записавшихся на карточке сходки; социальное доказательство поверх RSVP | средний | минимальный |
| «Кто что везёт» (потлак-лист) | список позиций (еда, колонка, настолки), участники разбирают по кнопке | высокий | низкий |
| Попутки | «еду из X, есть 2 места» / «ищу машину»; критично для загородных сходок | средний | средний |
| Трекинг взносов без платежей | «скинулись на домик: 8/12», статусы отмечает организатор вручную (в духе «варианта Б») | средний | низкий |

## Топ-5 кандидатов (оценка PM, 2026-07-17)

1. **Голосование за дату** — P1-кандидат, крошечное, бьёт в главный блокер создания сходок.
2. **Витрина «кто придёт»** — час работы поверх RSVP, растит конверсию.
3. **Фото-альбом + ретро-опрос** — закрывают «память», кормят ленту контентом.
4. **«Год в соли»** — лучший retention-ход и лучшая демонстрация ES-архитектуры.
5. **Квизмейстер** — докажет (или опровергнет) модульность платформы; только после аукциона v2.
