# Дизайн Mini App и веб-интерфейсов

Процесс: **дизайн-первый, через Claude** — экран проектируется в design-сессии (интерактивный HTML-макет/артефакт), утверждается здесь, и только потом верстается в `frontend/`.

## Правила

- Один экран = один файл-макет в этой папке (`meetup-summary.html`, `auctioneer-console.html`, …) + при необходимости заметка с решениями.
- Макет — это контракт для вёрстки: состояния (пусто/загрузка/ошибка), тёмная тема Telegram, мобильный вьюпорт 375px.
- Ключевые дизайн-решения (навигация, тема, компонентная база) фиксируются как ADR.

## Очередь экранов (приоритет из ROADMAP)

1. «Сводка сходки» + карточка сходки с RSVP (P1)
2. Календарь сходок (P1)
3. Лента лотов + карточка лота (P3)
4. Консоль аукциониста (P3, см. [спеку аукциона](../02_SERVICES/auction-module-spec.md))
5. Big Screen финала (P3)

Пока макетов нет — папка создана как якорь процесса.
