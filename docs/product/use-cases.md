# Словарь продуктовых сценариев

Словарь задаёт стабильные значения поля `use_case` в структурных логах. Он растёт вместе с продуктом: имя появляется только для сценария, который уже входит в утверждённый срез.

## Граница сценария

Один `use_case` начинается осознанным действием человека, проходит одной технической цепочкой и заканчивается наблюдаемым ответом. Отдельное имя требуется, когда действие:

- самостоятельно инициируется человеком;
- может независимо завершиться успехом или отказом;
- имеет собственный наблюдаемый результат;
- может быть повторено без повторения всего предыдущего пути.

Кадры одного взаимодействия, варианты результата, транспортные операции и виды отказа отдельными `use_case` не становятся. Их различают состояние ответа, поле `operation` и поля результата записи. Поэтому пустой и непустой список относятся к одному сценарию, а название, расписание и место не дробят заполнение формы по экранам. Имя `use_case` выводится из доменного действия человека, а не из имени транспорта; лексическое совпадение допустимо, если границы действия и операции естественно совпали.

Составной продуктовый путь может включать несколько значений `use_case`. Например, «Создать сходку» проходит через начало создания, заполнение данных и публикацию: эти действия приходят отдельными Telegram updates, получают разные `request_id` и независимо отвечают человеку.

## Первый вертикальный срез

| `use_case` | Действие человека | Наблюдаемый результат |
|---|---|---|
| `view_meetup_list` | Открыть список доступных сходок | Показан пустой список либо список видимых сходок |
| `start_meetup_creation` | Начать создание сходки | Создан черновик и показан первый шаг формы |
| `fill_meetup_details` | Передать очередную порцию данных формы | Данные приняты и показан следующий шаг либо предпросмотр |
| `publish_meetup` | Нажать «Опубликовать» | Сходка опубликована и показана ссылка на неё |
| `view_meetup` | Открыть выбранную сходку | Показана карточка с актуальными данными |

Сценарии соответствуют ходу [первого вертикального среза](../architecture/first-slice.md#ход), но не повторяют его кадры или внутренние вызовы сервисов.
