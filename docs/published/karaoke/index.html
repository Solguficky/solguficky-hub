Выберите номер. Тему узнаете вместе со всеми.

Переключение слайдов:
Управление во время доклада
  1. → / Пробел / клик — следующий слайд. ← — предыдущий.
  2. P — пауза таймера (например, на время вопроса из зала).
  3. F — полноэкранный режим. Esc — выйти в меню.
  4. Полоска внизу экрана показывает, сколько осталось до автосмены слайда. Слайдам с таблицами таймер сам добавляет 10 секунд.

Меню работает без интернета. Если что-то не так с браузером, откройте папку «Доклады (PPTX)» — там те же презентации для PowerPoint.
