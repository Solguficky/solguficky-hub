# 2026-09-12 — Рабочее дерево приезжает с таргетами, которых нет в Git, и гейт от этого красный

- **Контекст:** PER-99, дерево `.claude/worktrees/rfc-008-server-setup-review-497be3`, `just check-agent-tools`.
- **Наблюдение:** гейт упал на 52 строках вида «missing target `.agents/skills/<имя>`» при диффе из четырёх markdown-файлов. Причина не в правке и не в отсутствии источников: дерево, созданное приложением, получает `.claude/` целиком, вместе с 52 внешними таргетами, которых в Git нет, а `.agents/skills/` наполняется только из Git и содержит 15 каталогов `proj-*`. Отметки времени всех 67 каталогов в `.claude/skills/` совпадают с моментом создания дерева. `check-generated.sh` сверяет два таргета между собой, поэтому асимметрия читается как рассинхронизация. Контрольный опыт: дерево, созданное `git worktree add`, даёт 15 против 15, и `just check-agent-tools` в нём зелёный. `check-agent-tools` стоит первым в рецепте `verify`, поэтому остальные проверки не запускаются вовсе.
- **Последствие:** двенадцать рецептов прогнаны поодиночке, чтобы доказать нулевой код возврата, и в отчёте пришлось писать «красный по окружению» — то есть гейт не нёс информации о правке. Попытка привести дерево в рабочее состояние по документированному пути стоила отдельного отката, см. соседнюю запись.
- **Адресат:** Автоматическая проверка — `tools/skillshare/check-generated.sh`: он сверяет два таргета между собой, хотя источником правды объявлен `.skillshare/skills/`, и потому не отличает «таргет не разложен» от «таргет приехал мимо Git». Второй адресат — `AGENTS.md`, где путь «после клонирования или создания worktree» описан одинаково для обоих способов создания дерева, хотя начальное состояние у них разное.
- **Повторение:** первое наблюдение.
- **Следующий сигнал:** `just verify` красный на `check-agent-tools` в дереве, чей дифф не трогает `.skillshare/**`.
- **Перенесено:** [ADR-041](../../decisions/ADR-041-skillshare-targets-not-committed.md) и раздел про скиллы в [AGENTS.md](../../../AGENTS.md). Сигнал закрыт не правилом поведения, а снятием причины: закоммиченного состава, с которым сравнивали приехавший, больше нет, `check-generated.sh` потерял сверку таргетов, и все три способа создания дерева дают один и тот же состав после `skillshare sync -p`.
- **Статус:** переведено в правило
