# 2026-10-05 — Команда для ручного запуска пришла с заглушкой в угловых скобках

- **Контекст:** PER-236, [PR #349](https://github.com/Solguficky/solguficky-hub/pull/349). Владелец проходил drill escrow руками по командам, которые агент дал в чате.
- **Наблюдение:** в команде стояла заглушка `age -r <age1...> -o test.age`. Владелец вставил её как есть, и bash прочитал `<` как перенаправление ввода: `age1...: No such file or directory`. Агент признал ошибку и дал вариант без ручной подстановки — `age -r "$(age-keygen -y test.key)"`. Следующим же сообщением он выдал ту же форму `scp test.age <vps>:~/escrow-drill/`; сломалась ли она у владельца, по логу не видно.
- **Последствие:** лишний ход владельца со скриншотом посреди ручной процедуры с секретами, где каждая заминка — повод ошибиться ещё раз.
- **Адресат:** Норматив — правило требует суждения и проверяется на review. Ближайшее место — [docs/STYLE.md](../../STYLE.md), но он регулирует документы, а не ответы в чате; где живёт правило для команд, которые агент отдаёт владельцу на ручной запуск, решает владелец.
- **Повторение:** первое наблюдение. Повтор с `<vps>` случился в той же сессии и независимым случаем не считается.
- **Следующий сигнал:** в другой задаче или сессии команда для ручного запуска ломается при вставке как есть из-за заглушки, которую оболочка разбирает как синтаксис.
- **Статус:** наблюдение
