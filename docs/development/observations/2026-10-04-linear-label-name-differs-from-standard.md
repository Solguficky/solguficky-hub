# 2026-10-04 — Метка компонента бота в нормативе не совпадает с Linear

- **Контекст:** PER-435, заведение задачи-последователя [PER-466](https://linear.app/anticnvm/issue/per-466) скиллом `proj-create-task`; таблица меток в [linear.md](../../standards/backlog/linear.md).
- **Наблюдение:** норматив называет метку группы `SFG` для бота хаба `Hub Bot`, а в Linear такой метки нет. `save_issue` с `labels: ["Hub Bot", "Feature"]` отказал с «Could not find label», и задача завелась только с `Telegram Bot` — той же меткой помечена и [PER-439](https://linear.app/anticnvm/issue/per-439).
- **Последствие:** лишний круг вызова к Linear. Агент, который не стал бы искать существующую метку, завёл бы задачу без `SFG` или с ошибкой, а норматив с таблицей расходится молча — проверки бэклога нет по построению.
- **Адресат:** Норматив — таблица меток в `docs/standards/backlog/linear.md`, либо переименование метки в Linear; что из двух источник правды, выбирает владелец.
- **Повторение:** первое.
- **Следующий сигнал:** заведение или правка задачи по таблице меток норматива отказывает в Linear из-за имени метки, которого там нет.
- **Статус:** наблюдение
