# 2026-11-13 — Оркестратор написал исполнителю «чекпоинт не нужен» вопреки прямому запрету скилла

- **Контекст:** эпик [PER-740](https://linear.app/anticnvm/issue/per-740), лист [PER-749](https://linear.app/anticnvm/issue/per-749), ответ оркестратора исполнителю после решения владельца по Q-10. Скилл [`proj-run-epic`](../../../.skillshare/skills/proj/proj-run-epic/SKILL.md), раздел постановки: «Не пиши „чекпоинт не нужен“ и не отменяй шаги контура: чекпоинт срабатывает по условию норматива».
- **Наблюдение:** передавая решение владельца, оркестратор написал, что дополнение ADR-076 п. 7 чекпоинта не требует. Правило против этого стояло в загруженном скилле дословно. Оркестратор заметил ошибку сам и отправил поправку отдельным сообщением (`msg_d6393829e439`): чекпоинт — по условию норматива. Исполнитель прошёл контур по нормативу.
- **Последствие:** без поправки исполнитель мог пропустить чекпоинт плана на правке ADR, то есть на решении, которое показывают владельцу. Обошлось одним лишним сообщением.
- **Адресат:** Скилл — `proj-run-epic`. Правило в нём есть и поведение не изменило. Кандидат — проверка отправляемого текста перед `send` и `reply` на формулировки отмены шагов контура. Хук на команду Orca подошёл бы, если такие тексты повторятся. Пока это одна сессия.
- **Повторение:** первое наблюдение.
- **Следующий сигнал:** в другой сессии оркестратор или ведущий агент пишет исполнителю, что шаг контура (чекпоинт, ось ревью, гейт) не нужен, хотя норматив его не снимает.
- **Статус:** наблюдение
