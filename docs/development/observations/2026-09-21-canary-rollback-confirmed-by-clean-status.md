# 2026-09-21 — Откат канареечной правки подтверждён чистым `git status`, а дефект остался

- **Контекст:** PER-102, [PR #146](https://github.com/Solguficky/solguficky-hub/pull/146), коммиты `fc73d94` (канарейка) и `b3048de` (восстановление), файл `apps/identity/internal/server/allowed_usernames_internal_test.go`.
- **Наблюдение:** критерий приёмки задачи требовал показать, что намеренная ошибка линта роняет джобу CI. Ошибка внесена отдельным коммитом и подтверждена живым прогоном, после чего откат сделан командой `git checkout -- apps/identity/internal/server/allowed_usernames_internal_test.go`. Команда вернула файл из индекса, а индекс уже содержал канареечный коммит: рабочая копия стала побайтово равна `HEAD`, `git status --short` напечатал пусто, и попытка закоммитить восстановление упала с `nothing to commit, working tree clean` — при том что удалённый `t.Parallel()` остался на месте. Дефект нашёлся сверкой рабочего файла с ревизией до эксперимента (`git show 958b583:apps/identity/internal/server/allowed_usernames_internal_test.go | diff - <файл>` — расхождение в одну строку), а признаком состоявшегося отката стала пустая разница `git diff 958b583 HEAD` уже после правки через Edit.
- **Последствие:** «чистое дерево» прочитано как «эксперимент откатан», хотя откат не произошёл. Ошибка канарейки намеренная и в одну строку, поэтому пользы она не унесла; тот же признак на другом эксперименте означает уехавшую в pull request намеренную правку при зелёном гейте. Механический `git status` здесь не отличает исправленное состояние от испорченного.
- **Адресат:** Скилл — тот, который возьмёт канареечные проверки: сегодня намеренная правка ради проверки гейта не описана ни в [контуре](../agent-execution-loop.md), ни в скиллах, ближайшая поверхность — шаг сдачи `proj-deliver-task`. Верхние адресаты не подходят: ревизия, от которой откатывают эксперимент, известна только агенту и командой без суждения не проверяется.
- **Повторение:** первое наблюдение. Родственная запись 2026-09-14 про `sed` — другой механизм: там частично отработавшая команда испортила файл, здесь команда отката не отработала вовсе, а состояние выглядело исправным.
- **Следующий сигнал:** чистое дерево или пустой `git diff` против `HEAD` приняты доказательством откатанной экспериментальной правки, либо такая правка уехала в pull request.
- **Статус:** наблюдение
