# 2026-10-05 — План пообещал действие агента, которое харнесс отклонил

- **Контекст:** PER-237, [PR #356](https://github.com/Solguficky/solguficky-hub/pull/356). Чекпоинт плана [контура](../agent-execution-loop.md), развилка «кто что делает на живом хосте».
- **Наблюдение:** план предложил: «агент пишет playbook и гоняет его из WSL поэтапно», и владелец это принял. Под это владелец выбрал вариант с временным файлом пароля `sudo`, чтобы агент мог запускать прогоны без интерактивного ввода. Первый боевой прогон `ansible-playbook … --tags users` под root классификатор auto mode Claude Code отклонил с причиной `[Production Deploy]`. Схему перестроили: каждый боевой прогон запускал владелец по командам агента, а решение о файле пароля пропало.
- **Последствие:** один круг вопросов владельцу ушёл на решение, которое не понадобилось. Распределение работы между агентом и владельцем перестраивалось уже посреди живых шагов. Пробные прогоны агент делать мог, а боевые нет, и это различие план не называл.
- **Адресат:** Норматив — раздел «Контракт среды» в [agent-execution-loop.md](../agent-execution-loop.md): может ли агент в данном харнессе исполнять действия на боевой среде, выясняется до того, как план это пообещает. Автоматическая проверка не подходит: решение классификатора зависит от действия и режима сессии, заранее командой не запрашивается.
- **Повторение:** первое наблюдение. Записей про классификатор или auto mode в журнале нет.
- **Следующий сигнал:** в другой задаче план или чекпоинт обещает действие агента, а харнесс затем отклоняет его по своей политике.
- **Статус:** наблюдение
