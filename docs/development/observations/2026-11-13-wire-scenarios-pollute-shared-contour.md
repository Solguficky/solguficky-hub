# 2026-11-13 — Сценарии провода, которые публикуют сходки, засоряют общий контур для соседних сценариев

- **Контекст:** эпик [PER-740](https://linear.app/anticnvm/issue/per-740), лист [PER-749](https://linear.app/anticnvm/issue/per-749) ([PR #714](https://github.com/Solguficky/solguficky-hub/pull/714)). Новые сценарии провода бота хаба в `tests/contour/bot-wire/`, джоба `contour`.
- **Наблюдение:** сценарии листа публиковали сходки и оставляли их в контуре. На первом коммите PR джоба `contour` покраснела: соседние сценарии читали список сходок и находили там чужие. Исполнитель починил это отменой своих сходок в конце сценария. Следующий лист, [PER-879](https://linear.app/anticnvm/issue/per-879), получил об этом отдельное предупреждение в постановке оркестратора.
- **Последствие:** лишний круг CI на листе. Сценарии провода делят один контур, и порядок их запуска делает такой отказ зависимым от соседей.
- **Адресат:** Автоматическая проверка — test kit провода (`apps/hub-bot/testkit/`, `openBotWire`): сценарий получает изоляцию данных или уборку своих сходок без ручной отмены. Скилл ниже по таблице не нужен: изоляция проверяется прогоном, а не суждением.
- **Повторение:** первое наблюдение.
- **Следующий сигнал:** в другой задаче `contour` краснеет, потому что сценарий видит сходки, опубликованные другим сценарием.
- **Статус:** наблюдение
