# 2026-11-21 — Внешнее ревью Codex читает только первые 32 КБ корневого `AGENTS.md`

- **Контекст:** эпик [PER-908](https://linear.app/anticnvm/issue/per-908), лист [PER-907](https://linear.app/anticnvm/issue/per-907) ([PR #735](https://github.com/Solguficky/solguficky-hub/pull/735)), внешнее ревью Codex на шаге ревью контура. Корневой [AGENTS.md](../../../AGENTS.md) — 83 244 байта. Проектная конфигурация Codex `.codex/config.toml` генерируется из `.rulesync/` и лимит документа проекта не задаёт.
- **Наблюдение:** по отчёту сдачи Codex загрузил из корневого `AGENTS.md` только 32 КБ из 83. Это граница Codex для документа проекта по умолчанию. Хвост файла, в том числе «Критические правила», «Стандарты и локальные правила» и «Agent skills», внешнему ревьюеру не виден.
- **Последствие:** внешнее ревью сверяет дифф с правилами, которых не видит. Нарушение критического правила оно пропустит не по ошибке модели, а потому что правило не попало в контекст. Ревью при этом выглядит полным.
- **Адресат:** Автоматическая проверка — рецепт в `verify`: корневой `AGENTS.md` не длиннее лимита документа проекта Codex, либо `.rulesync/` задаёт Codex лимит не меньше размера файла и `just check-mcp` это сверяет. Правило в `AGENTS.md` не подходит: агент, у которого хвост файла обрезан, его не прочтёт.
- **Повторение:** первое наблюдение.
- **Следующий сигнал:** в другой задаче Codex сообщает об обрезанном `AGENTS.md` или пропускает нарушение правила из хвоста корневого `AGENTS.md`.
- **Статус:** наблюдение
