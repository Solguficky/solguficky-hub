# 2026-11-11 — Поиск открытого PR задачи по номеру находит чужой PR, где номер только упомянут

- **Контекст:** раздел «Захват задачи» [issue-tracker.md](../../agents/issue-tracker.md) — сигнал «открытый pull request» читается командой `gh pr list --state open --search "PER-N"`. Сессия оркестратора эпика [PER-740](https://linear.app/anticnvm/issue/per-740) и сессия исполнителя листа [PER-743](https://linear.app/anticnvm/issue/per-743).
- **Наблюдение:** в сессии оркестратора `gh pr list --state all --search "PER-744"` и тот же поиск по `PER-749` вернули [PR #601](https://github.com/Solguficky/solguficky-hub/pull/601) «[PER-741] Решить модель организаторов сходки». Номера там встречаются только в тексте, а не в заголовке и не в ветке. Оркестратор заметил подмену и перешёл на `--search "PER-N in:title"`. Исполнитель PER-743 в своей сессии получил то же самое и вынес это кандидатом рефлексии: поиск находит чужой PR, упоминающий номер в тексте, и признак занятости надо читать по ветке.
- **Последствие:** у задачи без своего PR поиск возвращает чужой, а в постановке и описаниях PR эпика номера соседних листьев упоминаются почти всегда. С `--state open` такой ответ читается как «задача занята», и контур останавливается на ложном сигнале захвата. В этот раз ложная занятость не случилась только потому, что упомянувший PR был уже слит.
- **Адресат:** Скилл — через контракт [issue-tracker.md](../../agents/issue-tracker.md), раздел «Захват задачи», который скиллы `proj-start-task` и `proj-run-epic` подставляют в свои шаги. Команда сигнала — поиск по ветке `feature/PER-N` (`gh pr list --head`) или по заголовку `in:title`.
- **Повторение:** второй независимый случай в той же записи — две сессии разных задач: оркестратор эпика (поиск по PER-744 и PER-749) и исполнитель PER-743.
- **Следующий сигнал:** проверка захвата по команде из контракта возвращает PR, чей заголовок и ветка относятся к другой задаче.
- **Правило из двух случаев:** сигнал «открытый pull request задачи» читается по ветке `feature/PER-N` или по номеру в заголовке, а свободный поиск по номеру в тексте признаком захвата не считается.
- **Статус:** вынесено на обсуждение
