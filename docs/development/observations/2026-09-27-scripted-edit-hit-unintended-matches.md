Второй случай: скрипт вставлял в `tests/telegram-live/session.test.ts` строку с `\\n` и `\\"`. Три слоя экранирования — heredoc, строка Python, строка TypeScript — дали в файле литеральный перевод строки внутри строкового литерала. Typecheck упал с `TS1002: Unterminated string literal`, и строку пришлось переписать через Edit.

Поймала её сверка числа строк в `--stat`, а не проверка. Во втором случае ушёл лишний круг typecheck, lint и L0. Edit в обоих случаях отказал бы сам: он требует единственного совпадения и принимает текст без слоёв экранирования.
