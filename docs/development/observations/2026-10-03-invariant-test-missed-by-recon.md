# 2026-10-03 — Тест, который держит ломаемый срезом инвариант, не дошёл до разведки, и выбор ушёл мимо чекпоинта

- **Контекст:** PER-449, дерево `orca/workspaces/solguficky-hub/per-449-auction`, [PR #318](https://github.com/Solguficky/solguficky-hub/pull/318). [`proj-start-task`](../../../.skillshare/skills/proj/proj-start-task/SKILL.md), шаг 4, артефакт разведки. Тест `PublishProfile_MatchesHubComposition` в `infra/apphost/AppHost.UnitTests/ClusterPublishTests.cs` требует, чтобы профиль публикации `cluster` совпадал с локальным `hub`.
- **Наблюдение:** срез добавлял Auction в профиль `cluster`, то есть ломал инвариант «`cluster` = `hub`». В `.work/PER-449/recon.md` из `ClusterPublishTests.cs` попали только строки 33–41 и 49–66. Тест, который держит равенство профилей, назван не был, хотя рядом в артефакте записано, что `hub` совпадает с `cluster`. Два планировщика читали только артефакт, и вопрос «входит ли Auction в локальный `hub`» не поставил ни один. Владелец на том же чекпоинте ответил на три других вопроса за четыре минуты. Тест упал при реализации. Агент сам выбрал «`cluster` = `hub` + `auction`», переписал тест и вынес выбор в «Отклонения от плана» с пометкой, что решение за владельцем.
- **Последствие:** решение о составе топологии — какие сервисы поднимает локальный `hub` — принято исполнителем и дошло до владельца только в теле pull request, после гейта. Если владелец выберет иначе, переделка пойдёт после ревью, а не до кода.
- **Адресат:** Скилл — `proj-start-task`, шаг 4: тесты изменяемых файлов, чьи утверждения срез ломает, попадают в артефакт целиком по списку, с названием утверждения, а не выборкой диапазонов. Автоматическая проверка не подходит: какой тест срез ломает, видно только по смыслу правки.
- **Повторение:** первое наблюдение этого механизма. Родственные записи: [2026-10-03](2026-10-03-recon-compressed-adr-principle.md) — там в разведке сжался принцип ADR, здесь до неё не дошёл тест, который держит инвариант; [2026-09-29](2026-09-29-test-norm-missed-by-recon-and-plan.md) — там не дошёл локальный норматив компонента.
- **Следующий сигнал:** при реализации падает существующий тест, утверждение которого срез меняет по смыслу, а артефакт разведки и план этот тест не называли.
- **Статус:** наблюдение
