# 2026-11-19 — Запись «Что нового» к видимому исправлению нашло только внешнее ревью

- **Контекст:** [PER-895](https://linear.app/anticnvm/issue/per-895), [PR #722](https://github.com/Solguficky/solguficky-hub/pull/722): «События», «Меню», шёпот `/events` и «Имя в аукционе» показывали скрытый черновик аукциона вместо опубликованного. Это видимое людям изменение бота, для которого норматив [release-notes.md](../../standards/git/release-notes.md) требует запись в `apps/hub-bot/release-notes/`.
- **Наблюдение:** исполнитель прошёл контур, а шаг 2 `proj-deliver-task` «Сверь документацию с кодом» не потребовал записи. Пропуск нашло внешнее ревью `codex review` (gpt-6-sol), запись дописана после него. Скилл берёт адреса сверки из раздела «Сверка документации» [verification-gate.md](../../agents/verification-gate.md): там рецепт `justfile`, «Карта репозитория», `docs/standards/` и `contracts/proto/`, а записи «Что нового» нет. Норматив `release-notes.md` и слова «Что нового» не называет ни один `proj-` скилл. Соседние листы эпика ([PER-884](https://linear.app/anticnvm/issue/per-884), [PER-686](https://linear.app/anticnvm/issue/per-686), [PER-885](https://linear.app/anticnvm/issue/per-885), [PER-900](https://linear.app/anticnvm/issue/per-900)) записи добавили, а [PER-896](https://linear.app/anticnvm/issue/per-896) осознанно решил, что запись не нужна. Сколько из них знали правило по памяти, а сколько нашли по коду соседних записей, отчёты не говорят.
- **Последствие:** без внешнего ревью исправление ушло бы в мерж без записи, и пост «Что нового» в «Помощи» его бы не показал. Внешнее ревью здесь закрыло дыру шага сверки, которую должен закрывать сам контур.
- **Адресат:** Скилл — адреса сверки шага 2 `proj-deliver-task`, то есть раздел «Сверка документации» `docs/agents/verification-gate.md`: строка «видимое людям изменение бота — запись в `release-notes/` пакета по `release-notes.md`». Автоматическая проверка выше не подходит: видно ли изменение людям, решает суждение, а не путь файла.
- **Повторение:** первое наблюдение.
- **Следующий сигнал:** в другой задаче видимое людям изменение бота доходит до ревью, приёмки или владельца без записи «Что нового», и пропуск находит не шаг сверки документации.
- **Статус:** наблюдение
