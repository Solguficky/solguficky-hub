# 2026-10-08 — Сценарий провода написан по угаданным подписям, без прохода пультом

- **Контекст:** PER-543, [PR #396](https://github.com/Solguficky/solguficky-hub/pull/396). Новый сценарий `tests/contour/bot-wire/auction/bidding.test.ts`: администратор заводит лот и открывает неделю, участник и гость ставят через оба бота против настоящего Auction.
- **Наблюдение:** агент прочитал cookbook [bot-consoles.md](../bot-consoles.md), где сказано, что пульт нужен для прохода с заранее неизвестным путём «до того, как закреплять его сценарием». Тем не менее сценарий он написал сразу, по подписям из cookbook и по догадке. Каждый прогон чинил одно расхождение: «Ближайшие сходки» вместо «‹ Сходка», «Лоты» на карточке не сразу после включения аукциона, «Изменить лот» перед полями формы, «Цена и шаг сохранены», «· старт 1 000 ₽», неразрывный пробел в суммах, «К лоту» перед автоставкой, отставание read model Auction.
- **Последствие:** два полных подъёма контура с Auction и около двенадцати прямых прогонов против поднятого контура, примерно 20 минут на подгонку подписей до первой зелёной ставки.
- **Адресат:** Скилл — порядок работы над сценарием `tests/contour/bot-wire/`: сначала путь проходят пультом (`just contour-bot-console`), затем журнал `.work/bot-console/*.jsonl` переписывают в сценарий по таблице «Закрепить находку сценарием». Ни один `proj-` скилл сейчас не упоминает ни провод, ни пульт. Ближайший кандидат — `proj-write-grammy-bot`.
