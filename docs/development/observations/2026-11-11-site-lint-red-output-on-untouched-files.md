# 2026-11-11 — Линт API сайта показал красный вывод по чужим файлам, а гейт и CI остались зелёными

- **Контекст:** эпик [PER-740](https://linear.app/anticnvm/issue/per-740), лист [PER-747](https://linear.app/anticnvm/issue/per-747) ([PR #708](https://github.com/Solguficky/solguficky-hub/pull/708)), Windows. Рецепт `community-site-api-lint` в выборе `just verify-changed`.
- **Наблюдение:** исполнитель сообщил, что линт `community-site-api` дал красный вывод по правилу `useLiteralKeys` в файлах, которых срез не трогал. При этом в отчёте сдачи рецепт значится среди прошедших, а джоба CI зелёная. По отчёту исполнителя не видно, откуда расхождение: предупреждение без кода выхода, другая версия Biome локально или концы строк на Windows. Механизм не разобран.
- **Последствие:** исполнитель потратил время, чтобы понять, касается ли красный вывод его правки. Красный вывод при зелёном коде выхода учит не читать вывод линта.
- **Адресат:** Автоматическая проверка — рецепт линта либо падает на том, что печатает красным, либо этого не печатает. Сначала нужен разбор механизма.
- **Повторение:** первое наблюдение. Записи о [ложном красном второго verify](2026-09-21-second-verify-false-red.md) и [унаследованном красном](2026-10-04-inherited-red-spent-the-gate-budget.md) описывают красный код выхода, а не красный вывод при нулевом коде.
- **Следующий сигнал:** в другой задаче рецепт линта печатает нарушения по нетронутым файлам и выходит с кодом 0, или локальный линт расходится с джобой CI на тех же файлах.
- **Статус:** наблюдение
