# VISION: Платформа "Соль" для мероприятий

## О Проекте

"Соль" — это не просто Telegram-бот, а **полиглотная, микросервисная платформа** для организации и проведения мероприятий (сходок) для нашего комьюнити. Цель проекта — автоматизировать рутинные задачи организаторов, повысить вовлеченность участников и создать единое, удобное пространство для всей активности, связанной с мероприятиями.

Платформа строится вокруг идеи модульности, где ключевым стартовым модулем является гибкий и увлекательный **Аукцион**.

## Ключевые цели и ценности

*   **Польза (Utility):** Предоставить удобные инструменты для организации сходок.
*   **Вовлечение (Engagement):** Сделать участие в мероприятиях более интерактивным.
*   **Удержание (Retention):** Создать долгосрочную ценность через систему профилей и достижений.
*   **Гибкость:** Архитектура должна позволять легко добавлять новые "модули" в будущем.
