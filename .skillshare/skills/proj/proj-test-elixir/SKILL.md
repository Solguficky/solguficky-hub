# Тестировать Elixir-код

Стек, уровни и их границы заданы нормативом: [testing-strategy.md](../../../docs/standards/testing/testing-strategy.md), раздел «Стек Elixir». Форма имени — [naming.md](../../../docs/standards/testing/naming.md), раздел «Elixir». Язык ведёт `proj-write-elixir`. Здесь только последовательность работы; состав библиотек и версии по памяти не вводятся.

## 1. Выбери минимальный честный уровень

- Разбор настроек, отображение, ответ на внешний вход и любое решение, вынесенное в функцию, — L0, без дерева приложения, базы и контейнеров.
- Решение спрятано в процессе или за вызовом базы — сначала вынеси его в функцию с зависимостью аргументом по нормативу и проверь на L0, а не поднимай ради него узел.
- Миграции до listen, ответ границы по сети, публикация в настоящий JetStream и поведение при отказе шины — L1: настоящий узел поверх контейнеров.
- Уровень выше выбирается, только когда нижний физически не может доказать свойство.

## 2. Собери детерминированный сценарий

- Зависимость приходит аргументом-функцией. Та, которую сценарий не задействует, падает через `flunk`, а не отвечает успехом.
- Таймер процесса тест не ждёт: интервал отодвигается конфигурацией, тик тест делает сам.
- L1 кладёт конфигурацию по адресам своих контейнеров в `setup_all` и только потом стартует приложение; данные между тестами чистит `setup`.

## 3. Проверь то, что наблюдаемо

- Утверждение формулируется о наблюдаемом: поле записи, отметка строки, ответ границы, — а не о порядке вызовов реализации.
- Негативный путь проверяется наравне с основным: отказ шины, неизвестное имя, недопустимый параметр, лежащая база.
- Отказ проверяется по сути — коду, переменной в сообщении, — а не по полному тексту.

## 4. Поправь порог уровня

Добавил или удалил тест — поправь порог своего уровня в `test/test_helper.exs` тем же изменением. Новый L1-модуль несёт `@moduletag :integration` и лежит в `test/integration/`.

## 5. Проверь тест

Прогони `just <компонент>-test`; для L1 — `just <компонент>-test-integration`, ему нужен Docker. Ни один не печатает пропусков: пропуск роняет прогон.

Тест готов, когда он падает по той причине, ради которой написан, строка `test` читается предложением о поведении, а уровень — минимальный из тех, что доказывают свойство.
