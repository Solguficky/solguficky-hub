# Screen lint

Линтер экрана и форма каталога экранов — исполнение правил [дизайн-кода](../../../docs/design/bot/design-code.md#исполнение-правил) для бота хаба, бота аукциона и общего пакета аукционного интерфейса. Языковые правила — `proj-write-typescript`. Команды — `just screen-lint-*`.

- `src/catalog.ts` — форма записи каталога: класс сообщения, правило навигации, заголовок, родитель, признак денежного подтверждения `money` — только его «Да» красится `danger`, — `legacy` и именованные исключения `waive`. Сами каталоги держат боты рядом со своими экранами.
- `src/inspect.ts` — `inspectCall(config, method, payload)`: проверка вызова Bot API по каталогу и правилам, и накопитель найденного. Правило `body` читает только каркас текста — пустую строку после заголовка и одну заметку над ним, — а чем тело заполнено, держат тесты каталога ботов. Частное для дерева бота — символ метки, каталог, родитель из нескольких экранов, именованные пары кнопок — приходит настройкой `LintConfig`, а не кодом пакета. В имени именованной пары `#` стоит на месте числа в подписи, например «Материалы (#)|Лоты». Словарь у обоих ботов один и живёт здесь.
- `src/body.ts` — `inspectBody`: правила тела экрана до оболочки — `callback_data`, ширина ряда, число рядов. Его зовёт общий пакет аукциона.
- `src/index.ts` — вход пакета.

## Границы

- Сборки и `exports` нет. Потребитель — только тестовый код: test kit ботов и тесты пакета аукциона импортируют `src/index.ts` относительным путём и компилируют его своим конфигом, поэтому `tsconfig.json` потребителя держит `rootDir` у корня репозитория, а его `tsconfig.build.json` возвращает сборке свой каталог. Прод-код пакет не импортирует: образ бота о нём не знает.
- Зависимостей времени выполнения нет, и vitest пакет не импортирует: хук `afterEach`, снимающий найденное, лежит у каждого потребителя, иначе он взял бы второй экземпляр vitest из `node_modules` пакета.
- Правило, которое запись может снять исключением, — `WaivableRule`. Предел `callback_data` и цвет кнопки в него не входят. Причина исключения начинается с задачи: `PER-N: …`.
- Правка правила проверяется не только своими тестами: путь пакета поднимает в CI джобы обоих ботов и пакета аукциона, а L0 правил на настройке хаба — `apps/hub-bot/testkit/screen-lint.test.ts`.
